プライバシーポリシー

Hermes Workspace（以下「本アプリ」） / 最終更新日: 2026年10月28日

本アプリは、個人が自身のGoogleアカウントのデータを、自身のPC上で動作するローカルアシスタントから利用するために作成した個人用アプリケーションです。本ポリシーは、本アプリが取得・利用する情報の取り扱いを定めます。

1. 取得する情報

ユーザーが明示的にGoogleの認可画面で同意した範囲に限り、以下のデータにアクセスします。

  • Gmail（メールの読み取り・変更・送信）
  • Google カレンダー（予定の閲覧・作成・変更）
  • Google ドライブ（ファイルの閲覧・作成・変更）
  • Google ドキュメント、スプレッドシート（作成・編集・読み取り）
  • Google コンタクト（連絡先の読み取り）

2. 利用目的

取得した情報は、ユーザー自身の依頼に応じてメールの要約・検索・返信文の作成、予定の確認・登録、文書の作成・編集を行うためにのみ利用します。広告配信、プロファイリング、第三者への提供は行いません。

3. 保存場所と安全管理

  • OAuthのアクセストークンおよびリフレッシュトークンは、ユーザー本人のPC内（%LOCALAPPDATA%\hermes\ 配下）にのみ保存されます。
  • 認証情報を外部サーバーへ送信・複製することはありません。
  • メール本文等のデータは、ユーザーの依頼を処理するために必要な範囲で一時的に処理され、本アプリ独自のサーバーには保存されません。

4. 第三者提供

取得したデータを第三者へ販売・提供・共有しません。法令に基づく開示請求がある場合を除き、外部へ開示しません。なお、処理の一部はユーザーが選択したAIモデルの提供事業者を経由しますが、その範囲はユーザー自身の設定と依頼内容に限定されます。

5. データの削除と認可の取り消し

ユーザーはいつでも Google アカウントの「サードパーティ アプリとサービス」 から本アプリのアクセス権を取り消すことができます。取り消し後は本アプリはGoogleデータへアクセスできません。ローカルに保存されたトークンは、ユーザーがファイルを削除することで完全に消去されます。

6. Google API サービス ユーザーデータ ポリシーへの準拠

本アプリのGoogle APIからの情報利用は、 Google API サービス ユーザーデータ ポリシー （限定的使用の要件を含む）に準拠します。

7. 改定

本ポリシーを変更する場合は、本ページにて最終更新日とともに告知します。
