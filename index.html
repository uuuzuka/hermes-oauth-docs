Hermes Workspace

Personal OAuth integration for a single user's own Google account.

This site provides the homepage and privacy policy required by Google for a personal-use OAuth client. The application ("Hermes Workspace") is a locally-run assistant used by one individual, accessing only that individual's own Google account. It is not distributed to other users.
